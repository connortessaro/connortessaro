### Building

**[Ringi](https://ringi.dev)** — a Slack agent that replaces the status meeting. DMs each stakeholder, extracts their position with an LLM, and synthesizes a brief isolating the actual crux plus a committed recommendation.
<sub>TypeScript · Slack Bolt · Gemini · Drizzle/Postgres · Langfuse tracing on every model call</sub>

**[Phantom AI](https://phantom.codes)** — an anonymous AI inference proxy. Pay in crypto, get an OpenAI-compatible key. Requests route through Intel TDX and NVIDIA confidential-compute enclaves; secrets live in tmpfs and never touch disk; token accounting stops billing the instant a client disconnects.
<sub>Python · FastAPI · SQLCipher · Docker — [sanitized source](https://github.com/connortessaro/phantom-api)</sub>

**Harbor** — a lending marketplace. Real-time lead routing across branching eligibility constraints, a sequential buyer waterfall with pricing floors and bid-driven retries, fraud screening before submit.
<sub>TypeScript · SvelteKit · Zod · PostHog · Vercel</sub>

Most product source is private, so the links go to the live thing.
